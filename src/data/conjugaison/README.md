# Conjugaison data

Each file in `public/data/conjugaison/verbs/` represents one verb and contains **explicit** forms (not rules generated in the browser). The build script scans the directory and generates a single, gitignored `public/data/conjugaison/verbs-bundle.json` at build time. No manually maintained index is needed. The frontend fetches that bundle **only on the Conjugaison route**, versioned by the existing `public/data/content-version.json`. The file is generated by the `npm run dev` and `npm run build` scripts and should not be committed.

## File contract

```json
{
  "infinitive": "venir",
  "status": "learning",
  "group": "irregular",
  "forms": {
    "present": {
      "je": "je viens",
      "tu": "tu viens",
      "il": "il vient",
      "elle": "elle vient",
      "on": "on vient",
      "nous": "nous venons",
      "vous": "vous venez",
      "ils": "ils viennent",
      "elles": "elles viennent"
    }
  },
  "nonFinite": {
    "infinitif_present": "venir",
    "infinitif_passe": "être venu",
    "participe_present": "venant",
    "participe_passe": "venu",
    "gerondif_present": "en venant",
    "gerondif_passe": "en étant venu"
  }
}
```

Each tense can be added to `forms` with the same nine pronouns. `imperatif_present` only permits `tu`, `nous`, `vous`; its values contain no subject (e.g. `viens`). The shipped files include 17 personal tenses (16 listed in the curriculum plus futur proche) wherever applicable. All 6 non-finite forms are saved under `nonFinite`, without personal pronouns. The two imperative tenses only allow tu/nous/vous and can be absent for unsuitable verbs (including the rare past imperative of reflexive verbs).

- `status: "learning"`: included in randomly generated questions.
- `status: "learned"`: excluded from questions.
- `group`: `regular` or `irregular` for the user-facing filter.
- For past participles with `être`, subject agreement is explicit: `elle est venue`, `elles sont venues`. The personal forms `je`, `tu`, `on` default to masculine singular; `nous` and `vous` default to masculine plural.
- A missing tense/person combination is skipped (e.g. there is no imperative for `pouvoir`).
- The vocabulary review is independent of these files. Changing a JSON status requires a Git commit and a new deployment. The static website intentionally does not modify repository files.
- Quiz scores exist in React state for the duration of the session only. There is **no localStorage**.

Run `node scripts/validate-conjugaison.mjs` after editing the verb files. Update `public/data/content-version.json` when modifying conjugation data. The PR build runs the validator too.

The Conjugaison route is separate from the vocabulary review route; the conjugation JSON bundle is downloaded only when visiting Conjugaison (no 100+ individual network requests).

## Cache and release process

1. Add a single verb JSON file in `public/data/conjugaison/verbs/` (or edit its `status`), with all available personal and non-finite forms.
2. Run `npm run validate:conjugaison` to validate the schema and a minimum of four possible multiple-choice answers for every available form.
3. Increment the version in `public/data/content-version.json` (same sentinel used by lessons).
4. Run `npm run build` to regenerate the JSON bundle; CI performs the same build on PRs.
5. Deploy the build. Opening vocabulary review does not request `verbs-bundle.json`; opening Conjugaison uses `?v=<content-version>` with browser cache for the bundle.

Session statistics are ephemeral; the only persistent include/exclude switch is each verb's committed `status` field.
